# 📊 Tabela de Produtos

Projeto desenvolvido utilizando **Microsoft Power BI**, com o objetivo de trabalhar com dados de produtos e apresentar informações de maneira visual, organizada e intuitiva.

O repositório contém o arquivo do projeto Power BI (`produtos.pbix`), permitindo explorar o relatório e seus recursos de visualização de dados.

## 🎯 Objetivo do Projeto

Desenvolver um relatório de produtos utilizando o Power BI, aplicando conceitos de análise e visualização de dados para transformar informações em uma apresentação mais clara e facilitar sua interpretação.

## 🛠️ Tecnologias e Ferramentas

- **Microsoft Power BI Desktop** — desenvolvimento e visualização de relatórios.
- **Power Query** — preparação e transformação de dados, quando aplicável.
- **DAX** — criação de medidas e cálculos, quando aplicável.
- **Business Intelligence (BI)** — análise e apresentação de informações.

## 🚀 Como executar o projeto

1. Faça o download ou clone este repositório.
2. Instale o [Microsoft Power BI Desktop](https://www.microsoft.com/pt-br/power-platform/products/power-bi/desktop).
3. Abra o arquivo `produtos.pbix`.
4. Explore as visualizações e os recursos disponíveis no relatório.
5. Caso necessário, configure a conexão com a fonte de dados para atualizar as informações.
